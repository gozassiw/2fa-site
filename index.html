Need help?
Where do I find my secret key?
When you turn on two-factor login, the website shows a QR code and a text key, often under "Can't scan the code?". Copy that key and paste it above.
Why does the code keep changing?
Each code only works for 30 seconds. Use it before the bar runs out.
My code isn't working
Set your phone's time to automatic, and make sure you pasted the full key.
Is it safe?
The code is made inside your browser, like Google Authenticator. Keep your key private, like a password.
